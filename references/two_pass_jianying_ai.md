# 两遍剪映 AI（Doubao 通过 mac_computer_use_tool 操作剪映 GUI）

> 这一段**不是脚本自动化**，而是 Doubao 在剪映桌面端里用 `mac_computer_use_tool` 操控 GUI 完成。
> 原因：jianying-editor-skill v1.7 在 macOS 只能**生成草稿**，不能自动导出/自动点 AI（自动导出仅 Windows）。
> CodeBuddy 已把精确草稿准备好；最终 AI 处理与导出由 Doubao 在剪映 GUI 内执行。

## 总体顺序
1. 打开剪映，定位到 CodeBuddy 生成的草稿（或导入原素材）。
2. **第一遍剪映 AI**：智能字幕 / 初切，让字幕与镜头初版就位。
3. **第二遍剪映 AI**：AI 调色 / 配乐 / 一键成片，精修后导出。

---

## 第一遍剪映 AI（粗剪 / 初处理）

目标：把 CodeBuddy 精切草稿里的字幕校准好，并可做一次镜头初切。

建议操作（Doubao 用 mac_computer_use_tool 在 GUI 内点击）：
1. 启动「剪映专业版」，在左侧「草稿」列表双击打开 `<项目名>` 草稿。
2. 选中主视频轨道，点击顶部「**智能字幕**」→「**文稿匹配** / **识别字幕**」：
   - 让剪映基于语音重新识别字幕，与 CodeBuddy 写入的字幕轨比对；以剪映识别为准校正时间码与错字。
   - 专名（人名/地名/活动名）若被 ASR 写错，人工修正为正确写法后再落字幕。
3. （可选）若对节奏不满意：选中片段 → 右键「**剪口播**」或顶部「**AI 成片**」，让剪映做一次镜头初切作为底稿。
4. 确认字幕无误后 `⌘S` 保存，进入第二遍。

---

## 第二遍剪映 AI（精修 / 导出）

目标：做最终润色并导出成片。

建议操作：
1. 在已校字幕的草稿上，点击「**AI 调色**」套用合适滤镜（或手动调色）。
2. 点击「**智能配乐**」/「**一键成片**」让剪映补配乐与转场；检查封面、字幕位置、节奏。
3. 检查片头封面（CodeBuddy 已放 3s 封面卡片）是否合适，必要时替换。
4. 点击右上「**导出**」：分辨率按平台选 1080p，帧率 30，编码 H.264；选择导出路径。
   - **macOS 无自动导出，必须由 Doubao 在 GUI 内点导出**（这是自动化边界）。
5. 导出完成后向用户回报成片路径与时长。

---

## 注意事项
- 剪映不会实时刷新草稿：若看不到新草稿，**重启剪映**或点进其它草稿再返回。
- 若剪映正占用某草稿导致写入失败，先切回剪映主页再让 CodeBuddy 重新生成。
- 所有 GUI 操作须遵守用户当前剪映版本的实际菜单文案（不同版本按钮名称可能略有差异）。
- 不向剪映上传任何违反版权/隐私的素材；成片导出后提醒用户核实专名与肖像授权。

---

## 流程坑（踩过的坑，勿再犯）

**⚠️ 严禁跳过第一遍剪映智能粗剪。**

- **踩坑经过（2026-10-19 首次干蒸探店测试）**：图省事跳过了「第①步剪映智能粗剪」，直接把 8 个原素材拼接成一条长视频后喂给豆包理解。
- **后果**：
  1. 豆包在更长的原始视频上做理解，**多花了一笔 API token**（视频时长更长、抽帧更多）；
  2. 没经过剪映机械过滤（自动掐掉停顿、语气词、废镜头）打底，**粗剪版应有的"干净底稿"缺失**，下游精切决策质量也受影响。
- **正确流程（必须严格按序）**：
  `素材` → `剪映智能粗剪（第一遍）` → `导出粗剪版` → `豆包理解粗剪版` → `CodeBuddy 精切` → `生成草稿` → `剪映 AI 第二遍（字幕/包装/补断点）` → `导出`
- **铁律**：下次测试**必须先由 Doubao 用 mac_computer_use_tool 操作剪映跑完第一遍粗剪、导出粗剪版**，再进入豆包理解。任何情况下都不能为省事跳过这一步。
